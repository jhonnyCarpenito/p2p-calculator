# P2P Trading Calculator

Aplicación web para **comerciantes P2P** que simula un ciclo completo de trading (USDT → Fiat → USDT), permite configurar fees de exchange y banco, y calcula el beneficio en tiempo real.

**Demo (GitHub Pages):** https://jhonnycarpenito.github.io/p2p-calculator/

---

## Cómo ejecutar

```bash
npm install
npm run dev
```

## Scripts

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build de producción |
| `npm run preview` | Previsualizar build |
| `npm run test:run` | Ejecutar tests |
